## Key NAR rules (summary)

| Topic | Rule | Source |
|---|---|---|
| Article types | Standard research, Methods, Critical Reviews & Perspectives, Database Issue, Web Server Issue. A Methods paper must "report novel techniques, significant advances in existing techniques, and/or demonstrate novel utility…". Validation must use real experimental data (comparative benchmarking). "Methods Online" is the historical NAR label for methods papers (e-numbered). | author-guidelines; criteria_scope; [1999 editorial](https://academic.oup.com/nar/article/27/20/i/1310706) |
| Alternative venue | NAR Genomics & Bioinformatics (NARGAB) lists Application Notes, Standard Papers, Methods Papers, **Methods and Benchmark Surveys** and Opinion Articles. Authors of benchmark surveys "should have a track record of publication within the field". Novel bioinformatics components must be open source. | nargab/why-publish; nargab/scope_and_criteria |
| Length | No word or figure limit for standard or methods articles. Concision is expected. | MS-F (2°), author-guidelines |
| Section order | Title, authors/affiliations, Abstract, (Graphical abstract file), Introduction, Materials and Methods, Results, Discussion (Results and Discussion may be combined), Data Availability, Supplementary Data, Acknowledgements, Author contributions, Funding, Conflict of interest, References. Materials and Methods comes before Results. | author-guidelines; MS-F (2°) |
| Abstract | One unstructured paragraph of ≤200 words. No URLs, citations, figure references or non-standard abbreviations. Only Database and Web Server abstracts carry a URL. | author-guidelines (search extract); MS-F |
| Graphical abstract | Required. 5:2 aspect ratio, minimum 127×50 mm (5×2 in), TIF/EPS/editable PDF at 300–600 dpi. Must not reuse a main or supplementary figure. No trademarked logos. | Ms_Prep_Database; MS-F/MS-S (2° for the general-track wording) |
| Title | No length limit stated. Should be specific and descriptive. Authors given as First I. Last, with full affiliations (department, institution, town, postcode, country) and the corresponding e-mail. ORCID required for the submitting author. | MS-F (2°) |
| Keywords | Not required by NAR; NAR articles do not print keywords. | MS-F (no mention) (2°) |
| Figures | Embed figures and legends in the text for review. Supply high-resolution files at submission or at the latest at revision (OUP figure guidelines: about 300 dpi for colour/halftone, 600–1200 dpi for line art, TIFF/EPS/PDF). Multipanel figures as one composite. Legends must stand alone. **Alt text** under each legend, starting "Alt text:". No colour charge. | MS-F (2°) quoting author-guidelines |
| Tables | Embedded and editable (not images). Minimal shading. Every table cited. | MS-F (2°) |
| Data and code | Release the data and code behind the results as a condition of publication, where ethically possible. A **Data Availability** statement is mandatory and goes at the end of the article. Code must be deposited in **Zenodo or FigShare with a DOI**, given in the Data Availability statement. GitHub alone is not acceptable as the primary archive. Resources must stay available for at least 5 years. Missing access can cause delay or editorial rejection. | author-guidelines; data_deposition_and_standardization |
| Software and versions | Reproducibility: give the versions of programs and statistical packages. Programs and web sites are cited in the text, not in the reference list. | MS-F (2°) |
| Supplementary data | Separate file(s), preferably PDF, not typeset. Every item cited in the main text. Text must include "Supplementary Data are available at NAR Online." | MS-F (2°) |
| References | Numbered in order of appearance; one reference per number. NAR style, e.g. `Capaldi,S., Getts,R.C. and Jayasena,S.D. (2000) Title. Nucleic Acids Res., 28, e21.` Journal names abbreviated (Chemical Abstracts style). | MS-F (2°) quoting author-guidelines |
| Funding | Funding statement required. NAR also asks for the "Funding for open access charge:" line. | MS-S (2°); NAR convention |
| Conflict of interest | Required for all authors ("Conflict of interest statement. None declared."). | MS-S (2°) |
| Author contributions | Required; CRediT encouraged. | MS-S (2°) |
| Cover letter | Required. Explain why the work fits NAR and give details of any earlier NAR submission. AI use must also be disclosed here. | MS-S; author-guidelines |
| Suggested reviewers | **At least six**, with names, affiliations and institutional e-mails. Independent of the authors, with no conflict of interest. | author-guidelines; policies |
| Preprints | Allowed (Author's Original Version, for example bioRxiv). After acceptance, update the preprint with the DOI. bioRxiv offers direct transfer to NAR. | policies; author-guidelines; [NAR preprint editorial](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC6326781/) |
| AI use | AI tools cannot be authors. Disclose any use (content or images, code, data processing, translation) in the **cover letter and in the Methods or Acknowledgements**. | author-guidelines (search extract); MS-F |
| LaTeX | Use the OUP template ("Modern Large" design). The initial submission is a single PDF; LaTeX sources are requested at revision. No line numbers or footnotes (Word guidance). | MS-F (2°) |
| Fees | Fully open access. APC about USD 4,381 (OUP, August 2026). No page or colour charges. | MS-F (2°) |
